# Описание содержимого страниц
## Главная лента
1. Шапка
	1. Название сайта
	2. Ссылки на тематические ленты
	3. Поисковая строка
2. Лента последних новостей из карточек
	1. Обложка (только у важных)
	2. Название
	3. Дата и время публикации
3. Подвал
	1. Контакты
	2. Копирайт
	3. Ссылки на справочные статьи

## Тематическая лента
1. Шапка
2. Баннер, позволяющий определить тему ленты
	1. Фоновое изображение
	2. Название темы
	3. Описание темы
3. Лента новостей
4. Подвал

## Новостная статья
1. Шапка
2. Основная часть
	1. Хлебные крошки
	2. Обложка
	3. Название
	4. Сведения о статье
	5. Текст статьи
	6. Способы поделиться статьёй
	7. Связанные статьи
3. Подвал

## Поисковая выдача
1. Шапка (уже без поисковой строки)
2. Поисковая строка
3. Настройки фильтров и сортировки
4. Список найденных статей
	- Выполнены в виде карточек, подобных тем, что на главной ленте
	- Подходящие ключевые слова и теги выделены
5. Выбор страницы для перехода
6. Подвал

## Справочные страницы
1. Шапка
2. Название страницы
3. Необходимая информация
4. Подвал

## Страница авторизации
1. Шапка
2. Форма
   1. Логин
   2. Пароль
3. Подвал

## Панель управления
1. Шапка
2. Список действий
   1. Создание статей
   2. Изменение статей
   3. Удаление статей
   4. Выбор статьи дня
3. Подвал
