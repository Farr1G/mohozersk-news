# Правила организации проекта

## Наименование файлов и папок
Для названий файлов и папок используются английские словосочетания с обязательным существительным. Вместо пробелов используются дефисы. Прописные буквы используются исключительно в аббревиатурах.

Для изображений позволительно использовать транслит. Вскоре он будет стандартизирован.

Примеры наименования файлов:
- скрипт на JS для генерации статей — `article-generation.js`'
- изображение разбитого снеговика для обложки — `razbityj-snegovik.jpg`
