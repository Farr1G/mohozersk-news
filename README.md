Новостной сайт INSERT_NAME о городе Мохозёрске, который позволяет читателям читать и искать статьи, а журналистам их публиковать.

# Условия
- Сайт предназначен для десктопных устройств, мобильная версия необязательна.
- Я знаю основы HTML, CSS, JavaScript и Lua. Фреймворками ранее я непользовался.
- Необходимо заполнить сайт относительно реальным содержимым: текстом и изображениями.
- Необходим способ добавлять, удалять и редактировать статьи.

Обязательные страницы:
- Основная и тематические ленты новостей.
- Новостные статьи, включающие текст и изображения.
- Поисковая выдача, на которой можно настроить фильтры (по тегам и названиям статей, дате написания) и сортировку.
- Справочные страницы: контакты, юридическая информация, справка об организации.

Дополнительные функции:
- Прогноз погоды.
- Система аккаунтов, позволяющая комментировать статьи, добавлять их в избранное и сообщать об ошибках.
- Рекламные баннеры по всему сайту.
- Адаптивность для мобильных устройств.
- Отображение скелетона при загрузке.

# Архитектура
Ленты новостей, страницы статей и поисковой выдачи генерируются на ходу на основе шаблона. Справочные страницы статичны.

Статьи представлены в формате JSON-файлов. В них указываются идентификатор, список тегов, дата публикация, название, изображение для обложки и оформленное в HTML содержание.

Сайт будет использоваться читателями и журналистами INSERT_NAME. Журналисты, в отличие от читателей могут добавлять, удалять и редактировать статьи.
